Node.js Standalone ZIP Installation Follow-Up Checklist (Windows)

1. Download Node.js ZIP
   - Go to https://nodejs.org/dist/latest-v22.x/
   - Download: node-v22.x.x-win-x64.zip

2. Extract Files
   - Extract to: C:\Tools\nodejs

3. Verify Files Exist
   - C:\Tools\nodejs\node.exe
   - C:\Tools\nodejs\npm.cmd
   - C:\Tools\nodejs\px.cmd (optional check)

4. Update PATH
   - Open System Properties > Advanced > Environment Variables
   - Add: C:\Tools\nodejs
   - Open a new PowerShell window

5. Verify Installation
   - node -v
   - npm -v

6. Configure Global npm Packages (Optional)
   - Create folder: C:\npm-global
   - Run: npm config set prefix C:\npm-global
   - Add C:\npm-global to PATH

7. Install Global Packages
   - npm install -g typescript
   - npm install -g playwright

8. Verify Global Packages
   - npm list -g --depth=0

9. GitHub Self-Hosted Runner Only
   - Restart runner service after updating PATH
   - Verify workflow can run: node --version

Troubleshooting
   - where node
   - where npm
   - Ensure no old Node.js paths remain in PATH.
